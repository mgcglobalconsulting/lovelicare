Tool: stitch.withgoogle.com · Required four-part formula: **Idea / Theme / Content / Image**

## The shared Theme block

Paste this verbatim as the `Theme:` of every prompt. Consistency across screens depends on it.

```
Theme:   Warm monochrome nude. Vagaro "Bare" palette ONLY: espresso #3C2B25,
         cacao #6E564E, greige #BDAEA9, shell #E9DAD1, bone #F4F1EB, plus
         ink #241915, sand #EADFD5, clay #A8938B, mist #FAF8F5. NO teal, NO
         blue, NO green, NO pink, NO gold fills. Every neutral leans warm
         red-orange — a single cool grey ruins it. All contrast is value
         contrast, not hue contrast.
         Display font Marcellus (headings 21px+). Body font Jost weight 300,
         17px, line-height 1.65 — generous and unhurried. Overlines in Jost
         500, 11px, uppercase, letterspacing 0.16em.
         Private-villa luxury: travertine, limewash plaster, teak, raw linen,
         unglazed ceramic. Golden-hour light from one low side angle, long
         soft shadows, mild haze. Generous whitespace, wide calm framing,
         asymmetric 7/5 composition — never perfect halves.
         Elevation is LIGHT not shadow: translucent panels, 1px warm hairline
         borders, backdrop blur. Shadows warm brown at low opacity, never black.
         NO tropical iconography — no palms as decoration, no hibiscus, no
         tiki, no shells, no script fonts, no gradient buttons, no gradient
         text, no decorative blobs, no drop shadows, no emoji, no badge icons.
         Reference: Aman resort brochure. NOT a Corona commercial.
```

## Iteration prompts

Format: `Target: / Change: / Keyword:` — one change at a time.

```
Target:  Service category cards on the homepage
Change:  Increase vertical padding and the gap between cards; let the panels
         breathe so the grid reads as composed rather than packed
Keyword: whitespace, visual hierarchy
```
```
Target:  Hero section
Change:  Deepen the scrim over the background image until the headline is
         clearly legible, but keep shadow detail open — never crush to black
Keyword: contrast, depth
```
```
Target:  Libra portrait block
Change:  Apply a fully rounded archway top to the image with square bottom
         corners, and widen the column to a 7/5 asymmetric split
Keyword: visual hierarchy, asymmetry
```
```
Target:  Credential row
Change:  Remove all icons and badge graphics; set as 11px uppercase with
         0.16em letterspacing and thin greige vertical dividers
Keyword: restraint, hierarchy
```
```
Target:  All panels and cards sitewide
Change:  Replace every drop shadow with a translucent surface, a 1px warm
         hairline border and backdrop blur
Keyword: glassmorphism, depth
```
